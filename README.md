# Виджет банковских операций клиента.
## Описание
В рамках обучения программированию создается виджет банковских операций клиента.

В модуле "masks.py" реализована работа фукций по маскировке номера карты пользователя и его номера счёта.

В модуле "widget.py" реализована работа функций по распознанию и выводу номера карты или счета, введённого пользователем, а также по распознанию даты, введённой пользователем.

В модуле "processing.py" реализована работа функции по сортировке списка словарей по статусу ключа "state" и функции по сортировке списка словарей по дате по убыванию.
